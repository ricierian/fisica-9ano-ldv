# Física 9º ano · LDV — listas interativas

Aplicativo web (PWA) com as listas de Física do 9º ano do Colégio Leonardo da Vinci Alfa (turmas 91, 92 e 93), Prof. Ricieri.

- `index.html`: o app inteiro (temas, listas, questões e resoluções).
- `manifest.webmanifest` e `icons/`: nome e ícone quando instalado no celular.
- `sw.js`: permite usar sem internet. Ao publicar mudanças, aumente `VERSAO`.

Endereços: `#/` início · `#/cinematica` tema · `#/cinematica/mu-vm` Lista 1 · `#/cinematica/mu-funcoes` Lista 2.
